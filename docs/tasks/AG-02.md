# AG-02 — New session entry points

- Status: ⬜ Not started
- Estimate: 3 h
- Dependencies: AG-01
- Plan: [editor-essentials.md](../plan/editor-essentials.md)

## Goal

Starting an agent is one click from wherever the user is looking at a project.

## Design

- **Session list:** a directory group's context menu gets "New Claude Code
  session", "New Codex session" and "New OpenCode session", showing only
  agents that are installed on the host (detection already knows which are
  present).
- **Session header:** a "New session" split button next to Resume: the main
  part starts the same agent in the session's directory, the menu offers the
  other agents.
- **Go to File:** the header's project name menu gets the same entries.
- **Keyboard:** Cmd/Ctrl+Shift+N starts the last used agent in the current
  project (the selected session's directory, or the Go to File project).
- The last used agent is remembered in preferences.
- Launch failures show the existing toast with the install hint. Hidden on
  hosts without the `newSession` capability.

## Done when

- Server-render tests cover the menus, the split button, hidden entries for
  agents not installed and for old servers.
