# PS-02 — Search over the wire

- Status: ✅ Done (2026-10-24)
- Estimate: 3 h
- Dependencies: PS-01
- Plan: [editor-essentials.md](../plan/editor-essentials.md)

## Goal

Make project search callable from the frontend for local, WSL and SSH hosts,
with cancel for searches the user has replaced by typing more.

## Design

- `engine.Backend.SearchFiles(ctx, dir, query)`; `Service.SearchFiles` checks
  `knownDirectory` and calls `files.Search`.
- `rpc`: method `searchFiles`, capability `SearchFiles`. The client sends
  `$/cancelRequest` when its context ends (existing behavior).
- App: `SearchFiles(dir, query, searchID)` and `CancelSearch(searchID)`. The
  app keeps a map from search ID to cancel function, so starting a search
  with a new ID does not need to wait for the old one. A host switch cancels
  every search.
- Frontend: `api.searchFiles` and `api.cancelSearch`, types in `types.ts`,
  `connectionStore.capabilities.searchFiles` (true locally). The browser mock
  searches its mock files.

## Done when

- Engine, app and RPC tests cover routing, unknown directories, capability
  absence on old servers, and cancel by ID.
- The frontend API test covers the missing-binding error.
