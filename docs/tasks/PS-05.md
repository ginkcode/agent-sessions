# PS-05 — Replace in the Search pane

- Status: ✅ Done (2026-10-24)
- Estimate: 4 h
- Dependencies: PS-03, PS-04
- Plan: [editor-essentials.md](../plan/editor-essentials.md)

## Goal

Replace from the Search pane the way VS Code does: a replace field, a preview
in every result, and replace one match, one file or all.

## Design

- A chevron left of the search field shows the replace field. While it has
  text, each match shows the old text struck through next to the new text.
- Hover actions: **Replace** on a match, **Replace all in file** on a file
  group, and **Replace all** next to the field (Cmd/Ctrl+Alt+Enter). Dismiss
  (×) removes a match or file from the result set without changing it.
- Replace all asks once: "Replace N matches in M files with “text”?". Single
  match and single file replaces do not ask.
- Clean files go through `replaceInFiles`. Files with an unsaved draft are
  changed in the draft as one undoable edit and stay unsaved; their tabs show
  the dot as usual.
- After replacing, open clean tabs show the new text as one undoable edit
  (their history is kept), the search runs again by itself, and a summary
  toast lists drafts, conflicts, skipped and failed files by name. Since the
  search reruns, a conflicted file shows its current matches without asking.
- Disabled with a reason when the host lacks `replaceFiles`, the search is
  not up to date, a file change or save is running, or the file is
  read-only. A dismissed match stays dismissed until the search text changes.
