# M6 — Portable sessions and cross-agent handoff: detailed plan

Covers tasks M6-01 … M6-17 from [TASKS.md](../../TASKS.md).

Users want to move a working session to another device, and to continue it in
a different agent. Native conversion between Claude Code, Codex and OpenCode
loses data, so cross-agent moves are a **handoff**: a Markdown document that
becomes the target agent's first message. Same-agent moves are a **restore**
of the verbatim native records.

## Contract: bundle manifest v1

`model.Transcript` is unchanged by this milestone. The M3-09 JSON export stays
a plain `[]Transcript`. The bundle is a new artifact.

File name: `<title>.agent-session.zip` (stdlib `archive/zip`).

```
manifest.json          format "agent-sessions.bundle", version 1
transcript.json        []model.Transcript (root + descendants), full fidelity
handoff.md             pre-rendered universal handoff (target-neutral)
native/<agent>/...     complete profile only: verbatim native records
```

`manifest.json`:

```json
{
  "format": "agent-sessions.bundle",
  "version": 1,
  "createdAt": "RFC3339",
  "appVersion": "…",
  "profile": "complete | share-safe",
  "source": {"agent": "claude-code", "agentVersion": "…", "id": "…",
             "cwd": "…", "repoRoot": "…", "gitBranch": "…"},
  "sessions": [{"ref": {"agent": "…", "id": "…"}, "parentId": "…",
                "native": [{"name": "…", "rootRel": "…", "sha256": "…", "size": 0}]}],
  "redaction": {"rules": {"pem": 0, "token": 0, "jwt": 0, "assignment": 0, "home": 0},
                "counts": 0},
  "handoff": "handoff.md"
}
```

- **complete** (default): restorable. Includes `native/`. The export dialog
  must warn that the file can contain secrets.
- **share-safe**: redacted, no `native/` entries, handoff-only.

Reader rules: reject zip-slip and absolute names, entries beyond count/size/
ratio caps, checksum mismatches, unknown major versions, and unsafe IDs
(`internal/manage` `isSafeID` / `uuidPattern`). The reader never uses bundle
paths as write targets.

## Why native records, not the transcript

`model.Transcript` is a display model. It clips tool output to 64 KiB, cuts
attachments, and drops Claude `parentUuid`/`toolUseResult`, Codex
`encrypted_content`, and OpenCode v1 patch/step parts. Native restore must
copy the raw records. The unified transcript is the universal *context*
format and the source for handoffs.

## Packages

- `internal/bundle` — pure. Streaming writer (sha256 per entry, 0600 temp file
  plus rename, same pattern as `internal/manage/config.go` `saveConfig`),
  validating reader.
- `internal/redact` — PEM private keys, `sk-`/`sk-ant-`/`ghp_`/`github_pat_`/
  `xox?-`/AWS `AKIA…` tokens, JWTs and `Bearer` tokens, `KEY=`/`password:`
  assignments and `.env`-style lines; home paths rewritten to `~` (adapted
  from `cmd/fixture-sanitize`). Returns counts per rule. Always on for
  share-safe; opt-in toggle for complete.
- `internal/handoff` — `Build(ts []model.Transcript, opts) (Doc, Report)`,
  deterministic Markdown. Text helpers (`extractMessageText`, `toolSummary`,
  `truncateUTF8`) move from `internal/index/fts.go` to `internal/model/text.go`.

### Handoff sections (priority order)

1. **Preamble.** "You are continuing a session started in X." Don't redo
   completed work; run `git status`/diff first. Tool-vocabulary note mapping
   source tools to the target's (Edit/Write ≈ apply_patch ≈ edit; Bash ≈ shell).
2. **Facts.** Original and current project dir, branch, model(s), dates,
   source session id, the original resume command.
3. **Goal and every user message verbatim.** Never dropped; middle-truncated
   only in extreme cases.
4. **Latest compaction summary** verbatim, when present.
5. **Working state** extracted from tool calls: files created/edited/deleted
   (Claude Edit/Write/MultiEdit, Codex apply_patch, OpenCode edit/write/patch),
   commands run with exit/error status, the latest todo list (TodoWrite /
   update_plan / todowrite), approved plans (ExitPlanMode input), subagent
   tasks and their final results, failures and errors in full.
6. **Timeline.** User messages and assistant text in full, reasoning
   (optional), tool calls as name + compact input + output head/tail.
7. **Last N turns verbatim** with full tool outputs.
8. **Closing.** Last user request, last assistant state, "continue from here".

**Budget** presets: Compact ≈25k, Detailed ≈80k (default), Full ≈150k,
Unlimited. Tokens are estimated as chars/4. Trim order: old tool outputs,
then old reasoning, then older assistant text condensed to its first
paragraph. Sections 1–5, 7 and 8 are kept. `Report` lists what was dropped
and the redaction counts; the preview shows it.

**Delivery** is "prompt + full context file": the first message carries
sections 1–5, 7 and 8, and the untrimmed timeline goes to
`$XDG_DATA_HOME/agent-sessions/handoffs/<id>-full.md` (0600, pruned after 30
days). The prompt tells the agent to read that file on demand.

## Native capture and restore (`internal/manage`)

Writes to tool stores stay inside `internal/manage` (opt-in, previewed HMAC
token, live guard, path safety).

- `capture.go` (read-only): Claude file set from `derivePaths` (main `.jsonl`
  plus the `<uuid>/` tree); Codex rollout files of the root and its
  descendants via `catalogIndex.descendants`; OpenCode via
  `opencode session export --standalone <id>` through `ExecFunc`/`runStandalone`,
  refused unless `v1MigrationCompleted`. `isProtectedName` always applied.
- `restore*.go`: gated by `[manage] allow_restore` (off by default).
  `PreviewRestore(bundle, target)` then `Restore(token)` follows the
  Preview/Delete HMAC flow (`seal`/`mac`, `tokenTTL`, re-plan plus `equalOp`).
  Fresh live guard, `pathSafety.classify`, collision checks (existing ID
  anywhere, `<uuid>/` dir present, any descendant ID). Collision choice:
  **Block** (default) or **Restore as copy** (new ID). Target dir is the
  original path if it exists, otherwise a user-picked directory (cwd remap).
  - **Claude:** write under `projects/<encode(newCwd)>/`. Rewrite only `cwd`
    (and `sessionId` for copies) in the JSONL records.
  - **OpenCode:** `opencode session import --directory <newCwd> <file>`.
  - **Codex:** place the rollout in `sessions/YYYY/MM/DD/` with
    `session_meta`/`turn_context` cwd rewritten, **only if M6-02 proves a
    copied rollout resumes without `state_N.sqlite` / `thread_history` rows**.
    Otherwise the action is hidden with an explanation.
  - Files written 0600, temp plus rename, no overwrite. A partial failure
    reports Moved/Remaining.
- `internal/index/refresh.go`: `Reintroduce(paths)` drops `SourceState` for
  those paths under the provider locks, then refreshes. `internal/app/manage.go`
  emits `NoteChanged` (mirror of `forget()`) and selects the restored session.

## App, CLI, UI

Bindings (each in all four `api.ts` places plus `types.ts`): `PreviewExport`,
`ExportBundle`, `BuildHandoff`, `SaveHandoff`, `HandoffCommand`, `OpenBundle`,
`PreviewRestore`, `Restore`, `PickDirectory`. Save/Open dialogs via Wails
runtime; an empty path means cancel. Fix the mock `copyResumeCommand`, which
hard-codes `--resume` for every agent.

Launch commands (`formatResumeCommand`-style quoting): `claude "<prompt>"`,
`codex "<prompt>"`, `opencode --prompt "<prompt>"`. The prompt is always
written to `handoffs/<id>-handoff.md` (next to `<id>-full.md`), and the
argument is only "Read <prompt file> completely to restore the context of an
earlier session, then follow its instructions and wait for my next request."
The handoff only restores context: the source session is often finished, so
the target agent summarizes the state and waits for the user instead of
resuming the last request on its own. This keeps the command one short line and far below Linux
`MAX_ARG_STRLEN` (128 KiB per argument). `ManageSettingsDialog` shows the
handoff file count and size and has a "Delete cache" button
(`HandoffCache`/`ClearHandoffCache`).

UI: `Export ▾` and `Continue in ▾` menus in `SessionHeader.svelte`;
`ExportDialog.svelte` (two profile cards, toggles, budget, size estimate,
redaction counts, sensitive-data warning); `HandoffDialog.svelte` (preview,
report, copy prompt / copy launch command / save); `ImportDialog.svelte` from
the sidebar footer (summary, restore, continue-in). Stores follow
`manage.svelte.ts`; pure helpers live in `frontend/src/lib/portable.ts`.
`ManageSettingsDialog` gains the "Allow restoring sessions from bundles" toggle.

CLI (`cmd/agent-sessions-cli`): `export <agent> <id> [--profile] -o`,
`handoff <agent> <id> --target <agent> [--budget]`, `inspect <bundle>`.
No CLI restore.

## Order

M6-01, M6-02, then the handoff slice (M6-08 → 09 → 10 → 11) — it writes to no
tool store. Then export (03–07, 12), import (13), restore (14–16), QA (17).
