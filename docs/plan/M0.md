# M0 — Foundation & Claude Code provider: detailed plan

Covers tasks M0-01 … M0-16 from [TASKS.md](../../TASKS.md). This file defines
the **shared contracts** (module layout, model types, provider interface,
JSONL reader) that every later milestone builds on. Change them here first,
then in code.

Formats referenced below are documented in [docs/formats.md](../formats.md).

---

## Conventions (apply to all milestones)

- **Go 1.26.** Module path: `github.com/ginkcode/agent-sessions` (rename if the repo lives elsewhere).
- **Dependencies:** stdlib first. Approved third-party libraries:
  - `github.com/tidwall/gjson`: fast field extraction on the scan path
  - `modernc.org/sqlite` (M1)
  - `github.com/fsnotify/fsnotify` (M2)
  - `github.com/BurntSushi/toml` (M3)
  - Wails v2 (M1)

  Anything else needs a note in the PR.
- **Dev tools** are pinned with Go 1.24+ `tool` directives in `go.mod` (`go get -tool …`), run via `go tool <name>`. Nothing needs to be installed globally.
- **Errors:** wrap with `fmt.Errorf("claude: scan %s: %w", path, err)`. Per-record problems go to `Diagnostics`, never returned as errors.
- **Context:** every long operation takes `ctx` and checks `ctx.Err()` at least once per file and every ~1000 records.
- **No global state.** Providers are constructed explicitly with their roots, which makes them trivially testable against `testdata/`.
- **Tests:** table-driven, run with `-race`. Golden files live next to the package in `testdata/golden/`.
- **Read-only:** open files with `os.Open` only, and SQLite with `mode=ro`. There is a grep check in CI (M5-06): no `os.Create`, `os.WriteFile`, `os.Remove` or `os.Rename` under `internal/provider/`.

## M0-02 `internal/model` (2 h)

```go
package model

type AgentID string

const (
    AgentClaude   AgentID = "claude-code"
    AgentCodex    AgentID = "codex"
    AgentOpenCode AgentID = "opencode"
)

// SessionRef uniquely identifies a session across all providers.
type SessionRef struct {
    Agent AgentID `json:"agent"`
    ID    string  `json:"id"`
}

func (r SessionRef) Key() string { return string(r.Agent) + ":" + r.ID }

type TokenUsage struct {
    Input      int64 `json:"input"`
    Output     int64 `json:"output"`
    Reasoning  int64 `json:"reasoning"`
    CacheRead  int64 `json:"cacheRead"`
    CacheWrite int64 `json:"cacheWrite"`
}

func (t TokenUsage) Add(o TokenUsage) TokenUsage

// MessageCounts follows SPEC §6: only conversation messages are counted.
type MessageCounts struct {
    User      int `json:"user"`
    Assistant int `json:"assistant"`
    ToolCalls int `json:"toolCalls"`
}

func (c MessageCounts) Total() int { return c.User + c.Assistant }

type SessionMeta struct {
    Ref              SessionRef    `json:"ref"`
    ParentID         string        `json:"parentId,omitempty"`
    ParentToolCallID string        `json:"parentToolCallId,omitempty"` // tool call that spawned this subagent
    SourcePath       string        `json:"sourcePath"`
    CWD              string        `json:"cwd"`
    RepoRoot         string        `json:"repoRoot,omitempty"` // main repo root (worktrees folded)
    CWDMissing       bool          `json:"cwdMissing,omitempty"`
    GitBranch        string        `json:"gitBranch,omitempty"`
    Title            string        `json:"title"`
    FirstPrompt      string        `json:"firstPrompt,omitempty"` // ≤ 300 runes, single line
    Model            string        `json:"model,omitempty"`
    AgentName        string        `json:"agentName,omitempty"` // e.g. "build", "explore", subagent type
    CreatedAt        time.Time     `json:"createdAt"`
    UpdatedAt        time.Time     `json:"updatedAt"`
    Counts           MessageCounts `json:"counts"`
    Tokens           TokenUsage    `json:"tokens"`
    CostUSD          float64       `json:"costUsd,omitempty"`
    Archived         bool          `json:"archived,omitempty"`
    Live             bool          `json:"live,omitempty"`
    LiveStatus       string        `json:"liveStatus,omitempty"` // "idle" | "busy" | ""
    AgentVersion     string        `json:"agentVersion,omitempty"`
}

type Role string

const (
    RoleUser      Role = "user"
    RoleAssistant Role = "assistant"
    RoleSystem    Role = "system"
)

type PartKind string

const (
    PartText       PartKind = "text"
    PartReasoning  PartKind = "reasoning"
    PartTool       PartKind = "tool"       // call + result paired
    PartPatch      PartKind = "patch"      // file change summary
    PartFile       PartKind = "file"       // image/attachment (lazy)
    PartCompaction PartKind = "compaction"
    PartNotice     PartKind = "notice"     // anything else worth showing
)

type ToolStatus string // "completed" | "error" | "pending" | "unknown"

type ToolCall struct {
    ID              string          `json:"id"`
    Name            string          `json:"name"`
    Input           json.RawMessage `json:"input,omitempty"`
    Output          string          `json:"output,omitempty"`           // ≤ 64 KiB
    OutputTruncated bool            `json:"outputTruncated,omitempty"`
    OutputRef       string          `json:"outputRef,omitempty"`        // blob key for full output
    Status          ToolStatus      `json:"status"`
    Child           *SessionRef     `json:"child,omitempty"`            // subagent spawned by this call
}

type FileRef struct {
    Name string `json:"name,omitempty"`
    Mime string `json:"mime,omitempty"`
    Size int64  `json:"size,omitempty"`
    Ref  string `json:"ref"` // blob key; content is never inlined
}

type Part struct {
    Kind  PartKind  `json:"kind"`
    Text  string    `json:"text,omitempty"`
    Tool  *ToolCall `json:"tool,omitempty"`
    File  *FileRef  `json:"file,omitempty"`
    Files []string  `json:"files,omitempty"` // patch: changed paths
}

type Message struct {
    ID          string     `json:"id"`
    Role        Role       `json:"role"`
    Time        time.Time  `json:"time"`
    Model       string     `json:"model,omitempty"`
    Parts       []Part     `json:"parts"`
    IsMeta      bool       `json:"isMeta,omitempty"`      // hidden by default
    IsSidechain bool       `json:"isSidechain,omitempty"`
    Tokens      TokenUsage `json:"tokens"`
}

type Transcript struct {
    Meta     SessionMeta `json:"meta"`
```

## M0-05 `internal/pathutil` (3 h)

```go
func NormalizeDir(p string) string // Clean → EvalSymlinks (if it exists) → strip trailing "/" (except root)
func Exists(p string) bool

type RepoInfo struct {
    Toplevel string // worktree top (dir containing .git)
    MainRoot string // main repository root (== Toplevel unless linked worktree)
}

type GitResolver struct { /* mu sync.Mutex; cache map[string]RepoInfo */ }

func NewGitResolver() *GitResolver
func (g *GitResolver) Resolve(dir string) (RepoInfo, bool)
```

**Algorithm for `Resolve`:** walk up from `dir` until `/`. At each level, stat `.git`:
- **`.git` is a directory:** `Toplevel = MainRoot = level`.
- **`.git` is a file:**
  1. Parse `gitdir: <path>` (relative paths are relative to `level`).
  2. If `<gitdir>/commondir` exists, read it (usually `../..`) and resolve against `gitdir` to get the common `.git` dir. `MainRoot` is its parent.
  3. Otherwise `MainRoot = level` (submodule case).
- Memoize every visited directory, including misses, since many sessions share prefixes.
- Missing directories: walk up from the nearest existing ancestor. A session whose cwd was deleted still folds into its repo.

**Tests (temp dirs, no `git` binary needed):**
- plain repo
- nested subdir
- linked worktree (hand-made `.git` file + `commondir`)
- relative `gitdir`
- symlinked cwd
- deleted cwd inside a repo
- non-repo
- cache hit count

## M0-08 `internal/jsonl` reader (3 h)

```go
type Reader struct { /* f *os.File; br *bufio.Reader; off int64; line int; max int */ }

func Open(path string, offset int64) (*Reader, error) // seeks to offset
func NewReader(r io.Reader, offset int64) *Reader      // for tests/fuzz

// Next returns the next complete line (without "\n").
// io.EOF is returned at the end. A trailing line without "\n" is NOT
// returned by Next, so Offset() stays at its start and a later resume
// re-reads it once it is complete.
func (r *Reader) Next() (line []byte, start int64, err error)

// Trailing returns the incomplete last line, if any, after Next hit EOF
// (Load uses it best-effort for live sessions).
func (r *Reader) Trailing() []byte

func (r *Reader) Offset() int64  // end of last complete line
func (r *Reader) LineNo() int
func (r *Reader) Close() error
```

**Implementation:**
- `bufio.NewReaderSize(f, 1<<20)`. Loop on `ReadSlice('\n')`; on `bufio.ErrBufferFull`, append to a scratch buffer and continue.
- Enforce a hard maximum line length of 256 MiB. Beyond it, skip to the next `\n` and report `ErrLineTooLong`, which the caller converts into a diagnostic.
- The returned slice is only valid until the next call. Document this, and have callers copy when they retain it.
- Strip `\r`. Skip empty lines.

**Fast field access:** use `gjson.GetBytes(line, "type")`. gjson skips nested
values, so the top-level `type` is found even though Claude puts
`"message":{…"type":"message"…}` **before** the top-level `"type"` in
assistant records. A naive `bytes.Index` is wrong here. Add a test for this
exact case.

**Tests:**
- lines around the 1 MiB buffer boundary and a 20 MiB line
- CRLF
- empty lines
- partial last line (`Offset` excludes it, `Trailing` returns it)
- open at offset
- nested-`type` ordering
- `BenchmarkScan38MB` using a generated file (the real file is not used in CI)

## M0-09 Claude metadata scan (3 h)

`scan.go`. One aggregator consumes lines and is **resumable**.

```go
type checkpoint struct {
    Meta            model.SessionMeta `json:"meta"`
    LastAssistantID string            `json:"lastAssistantId"`
    PendingUsage    model.TokenUsage  `json:"pendingUsage"` // usage of the current (unfinished) message.id
    AITitle         string            `json:"aiTitle"`
    Summary         string            `json:"summary"`
}

func (c *checkpoint) consume(line []byte, d *provider.Diagnostics) // gjson only; no full unmarshal
func (c *checkpoint) finalize(fileModTime time.Time) model.SessionMeta
```

**Field rules:**
- **Ref.ID:** filename stem; for subagents, `<parent>/agent-<agentId>`.
- **CWD:** first non-empty `cwd`, then `NormalizeDir`. `RepoRoot` comes from `git.Resolve(CWD).MainRoot`. `CWDMissing = !Exists(CWD)`.
- **GitBranch:** last non-empty value that isn't `HEAD`. **AgentVersion:** last `version`.
- **CreatedAt:** min `timestamp`. **UpdatedAt:** max `timestamp`, falling back to the file mtime.
- **FirstPrompt:** the first user record that counts (see the counting rule in formats.md), passed through `OneLine`/`TruncateRunes(300)`. Skip text starting with `<command-`, `<local-command-`, `Caveat:` or `<system-reminder>`.
- **Title:** last `ai-title`, then last `summary`, then `FirstPrompt`, then `"(untitled)"`. Applied in `finalize`.
- **Model:** last assistant `message.model`, ignoring `<synthetic>`.
- **Tokens:** usage is taken from the **last** record of each `message.id`. `PendingUsage` is overwritten on each record of the current id and committed into `Meta.Tokens` when the id changes and at `finalize`.

**Scan flow (`Scan(ctx, prev)`):**
1. Call `discover`.
2. For each source, `stat` it. If `prev` has the same size and mtime, skip it (unchanged, not returned).
3. If size ≥ prev size and a prev checkpoint exists, resume: unmarshal the checkpoint, `jsonl.Open(path, prev.Offset)`, and consume.
4. Otherwise (new file or shrunk), do a full read.
5. Store the new offset and checkpoint in `State`, and put the finalized meta in `Changed`.
6. `Removed` = paths in `prev` that no longer exist.
7. Run with a worker pool of `min(8, GOMAXPROCS)`, preserving deterministic output order (sort by path at the end).
8. Merge live info (M0-14) into the returned metas.

**Tests:**
- golden meta for each fixture
- the `ai-title`/`summary`/`FirstPrompt` fallback chain
- token accounting with split records
- `Removed` detection

## M0-10 Claude message counting + resume (3 h)

Counting lives in `checkpoint.consume`, following the rule in formats.md:
- **user:** `type=user`, `!isMeta`, `!isCompactSummary`, and content is a
  non-empty string or has at least one `text`/`image` block. Use gjson
  `message.content.#(type=="text")` etc. Skip the command-caveat texts
  listed in M0-09.
- **assistant:** `type=assistant` and `message.id != LastAssistantID`. Then
  set `LastAssistantID`. Ignore `isApiErrorMessage` records.
- **toolCalls:** add the number of `tool_use` blocks in each assistant record.

**Resume correctness test (acceptance):** for every fixture and for N random
cut points at line boundaries:
1. Scan the prefix up to the cut, which yields a checkpoint and offset.
2. Append the rest and resume from that point.
3. Assert the result is deep-equal to a single full scan.

Also cut inside a line (partial write) and assert the same final result.

## M0-11 Claude `Load` (4 h)

`load.go` uses `encoding/json` into narrow structs (only the fields we use;
`json.RawMessage` for `content` and `input`).

```go
type rawRecord struct {
    Type             string          `json:"type"`
    UUID             string          `json:"uuid"`
    Timestamp        time.Time       `json:"timestamp"`
    IsMeta           bool            `json:"isMeta"`
    IsSidechain      bool            `json:"isSidechain"`
    IsCompactSummary bool            `json:"isCompactSummary"`
    Subtype          string          `json:"subtype"`
    Content          string          `json:"content"`         // system records
    CompactMetadata  *compactMeta    `json:"compactMetadata"`
    Message          *rawMessage     `json:"message"`
    ToolUseResult    json.RawMessage `json:"toolUseResult"`   // not decoded in M0
}

type rawMessage struct {
    ID      string          `json:"id"`
    Role    string          `json:"role"`
    Model   string          `json:"model"`
    Content json.RawMessage `json:"content"` // string | []block
    Usage   *rawUsage       `json:"usage"`
}

type block struct {
    Type      string          `json:"type"`
    Text      string          `json:"text"`
    Thinking  string          `json:"thinking"`
    ID        string          `json:"id"`
    Name      string          `json:"name"`
    Input     json.RawMessage `json:"input"`
    ToolUseID string          `json:"tool_use_id"`
    Content   json.RawMessage `json:"content"` // tool_result: string | []block
    IsError   bool            `json:"is_error"`
    Source    json.RawMessage `json:"source"`  // image
}
```

**Algorithm (single pass, `jsonl.Reader` from offset 0):**
1. Keep `msgs []model.Message`, a pointer to the current assistant message
   with its `message.id`, and `tools map[string]*model.ToolCall`.
2. **`assistant`:** if `message.id` equals the current assistant id, append
   parts to it. Otherwise start a new `Message{Role: assistant, ID: message.id, Model, Time}`.
   - `text` becomes a text part.
   - `thinking` becomes a reasoning part.
   - `tool_use` becomes a tool part (`Status: pending`) and is registered in `tools`.
   - Update tokens from usage, last record wins.
3. **`user`:**
   - Decode content as a string, or as blocks.
   - For each `tool_result`, find `tools[tool_use_id]` and set `Output`
     (string content or joined text blocks) and `Status`
     (`error` if `is_error`, else `completed`).
   - Remaining `text`/`image` blocks form a user message, if any. Set
     `IsMeta` for `isMeta` or caveat/command text.
   - A user record with only tool results adds no message.
4. **Images** become `FileRef{Mime, Ref: "rec:<lineStart>:<blockIdx>"}`. Never inline the base64.
5. **Outputs > 64 KiB:** keep the first 64 KiB (at a rune boundary) and set
   `OutputTruncated` plus `OutputRef = "rec:<lineStart>:<tool_use_id>"`.
6. **End:** tools still `pending` stay pending if the session is live;
   otherwise mark them `unknown`.
7. `Load` also returns `Meta`: reuse the M0-09 aggregator over the same
   lines, feeding each line to both.

**`Blob(ctx, ref, key)`:**
- `rec:<off>:<id>` → seek to the offset, read one line, extract the full
  output or the image bytes (base64 decode).
- `file:<name>` → read `projects/…/<uuid>/tool-results/<name>`, after

## M0-16 Headless CLI (3 h)

`cmd/agent-sessions-cli/main.go` uses stdlib `flag` with subcommands (no cobra).

```
agent-sessions-cli scan  [--agent claude-code] [--json] [--all]   # --all includes subagents
agent-sessions-cli show  <agent> <id> [--json] [--meta] [--max-output 2000]
agent-sessions-cli detect
```

- `internal/provider/all.Providers(roots, git) provider.Set` constructs the
  providers. In M0 this is only Claude; OpenCode and Codex are added in M1.
- **`scan`:** `text/tabwriter` columns `AGENT  UPDATED  MSGS  CWD  TITLE`,
  sorted by `UpdatedAt` descending. A diagnostics summary goes to stderr.
- **`show`:** a readable transcript printout:
  - `▶ user 12:03`, text
  - `◀ assistant (model)`, then text, `[reasoning …]`, and
    `[tool bash ✓] input… → output…` (truncated to `--max-output`)
  - `── compacted ──`

  Meta messages are hidden unless `--meta` is passed.
- **`--json`:** encode `[]SessionMeta` / `Transcript` with 2-space indent.
- Exit codes: 0 for OK, 1 for an error, 2 for usage.

**Manual acceptance on this machine:**
- `scan` lists every current Claude session with sensible titles and counts
  (the number grows over time; verify it's ≥ the count from the previous run).
- `show` on the largest local session (≈38 MB at plan time) completes in
  under 1 s (measure with `time`).
- `--json | jq length` works.

## Proposed contract changes (post-M0, do not implement now)

Adopted from cross-plan review; all are **backward-compatible and deferred**:

1. **Multi-root identity (for M3-05).** If config supports extra storage roots
   per provider, `model.SessionRef` gains `Root string` (empty = default root,
   preserving the exact `agent:id` key format), `provider.Provider` gains
   `Root() string`, and `provider.Set` gains `Resolve(ref) (Provider, bool)`.
   Non-empty roots use a length-prefixed, unambiguous `Key()` namespace. M2's
   cache would need a migration to include `Root` in the session key and
   per-root scan state. Full proposal in M1-providers.md §"Proposed contract changes".
2. **Wails binding ergonomics (for M1-16).** `ToolCall.Input` should serialize
   as a pre-encoded JSON value (e.g. `json.Marshaler` returning `input` as raw
   JSON or `any`) so Wails generates `any` in TypeScript instead of
   `number[]` for `json.RawMessage`. `provider.Blob` results are wrapped in an
   app-layer `BlobResponse{Data, Mime, IsBinary}` so UTF-8 text avoids base64
   (raw `[]byte` becomes base64 over the Wails bridge). `MessageCounts` has no
   `Total()` in TS (struct methods don't cross the bridge); the frontend
   computes `user + assistant`.
3. **Optional provider extensions** (all additive, callers fall back to
   `Scan`/`Load` when unimplemented): `PathScanner` (targeted rescan of
   watcher-hit paths, M2-07), `RawRecordReader` (raw JSON inspector, M3-11).
   Full transcripts and FTS text: `GetMessages` paging already supports
   jump-to-message; `GetMessagesAround` is only added if plain paging proves
   insufficient (M2-06).

4. **Bundle manifest v1 (M6, new artifact — not a model change).**
   `model.Transcript` is unchanged, and the M3-09 JSON export stays a plain
   `[]model.Transcript`. The portable session file
   (`<title>.agent-session.zip`) is a separate contract owned by
   `internal/bundle`: `manifest.json` with `format: "agent-sessions.bundle"`
   and `version: 1`, plus `transcript.json`, a pre-rendered `handoff.md`, and
   (complete profile only) verbatim `native/<agent>/…` records. The full field
   list, reader rejection rules and the two profiles (complete / share-safe)
   are in [M6.md](M6.md) §"Contract: bundle manifest v1". Restore, the only
   new write path into a tool's store, reuses the M4 `internal/manage` HMAC
   preview flow behind a separate `allow_restore` opt-in.
